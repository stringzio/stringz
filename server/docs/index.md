# Stringz Documentation

Visual, no-code Web3 automations, compiled to Chainlink CRE workflows.

[[illustration]]

Stringz is a visual Web3 automation builder - "n8n for Web3". You drag nodes
onto a canvas: Chainlink price feeds, EVM events, contract calls, swaps, CCIP -
mixed with web2 apps like Slack, Discord, Telegram, Google Sheets, and Notion.
Stringz compiles the canvas into a [Chainlink CRE](https://docs.chain.link/cre)
workflow project that you run and deploy under your own keys.

**Tooling only.** Stringz never holds your keys, funds, or signatures - the
same way n8n or Zapier never touch your credentials. Generated workflows run
under your own Chainlink CRE account with your own secrets.
